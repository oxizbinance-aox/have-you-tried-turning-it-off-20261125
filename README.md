## The joke

Every help desk on earth has one answer for every problem: switch it off, switch it back on, hope for the best. This entry takes that tired troubleshooting ritual and points it somewhere no reboot can reach — a marriage. The punchline lands because the advice is technically sound for a router and hilariously useless for a relationship.

> Have you tried turning it off and on again? Your marriage, I mean.

## Run

```sh
node main.ts
```

The program prints the line above — one sentence, no dependencies, no setup.
